# 银行衍生物报价输出格式规范

## 输出要求

Agent 在完成报价查询后，必须严格按照以下格式输出，**不要输出任何无关内容**（如分析过程、解释说明等）。

> **重要提醒**：
> 1. 完成报价查询后，**只需要按照格式输出结果，不要输出任何其他内容**。不要输出你执行了什么命令、看了什么文件、做了什么分析。
> 2. **脚本执行成功后，直接返回脚本输出内容，不要进行额外组装**。脚本已经按照规定格式组装好完整输出，直接返回即可。

---

## 返回类型说明

本技能支持以下返回类型，请根据实际情况选择合适的类型：

### 1. error - 执行出错

当执行过程中发生错误时使用：
```
<<<TYPE_START>>> error <<<TYPE_END>>>
<<<CONTENT_START>>> 错误信息描述 <<<CONTENT_END>>>
```

### 2. price - 正常报价

当成功获取报价信息时使用：
```
<<<TYPE_START>>> price <<<TYPE_END>>>
<<<CONTENT_START>>> **产品名称**：{产品名称}

{报价表格}

{备注信息} <<<CONTENT_END>>>
```

### 3. chat - 需要用户补充信息

当需要用户提供额外信息时使用：
```
<<<TYPE_START>>> chat <<<TYPE_END>>>
<<<CONTENT_START>>> 需要补充的信息描述 <<<CONTENT_END>>>
```

---

## 输出格式

### 正常报价输出（price）

```
<<<TYPE_START>>> price <<<TYPE_END>>>
<<<CONTENT_START>>> **产品名称**：{产品名称}

{报价表格}

{备注信息} <<<CONTENT_END>>>
```

### 批量报价处理

报价脚本可能会返回一组报价信息（多个执行价或多个期限的报价），需要将这些报价信息**全部**在表格中返回，每行一个报价，供用户选择。

## 禁止事项

> **严格执行以下禁止事项！**

1. **禁止**输出分析过程或解释说明
2. **禁止**输出额外的文本描述（除了表格下方的备注信息）
3. **禁止**对报价结果进行解读或建议
4. **禁止**在输出中提及你执行了什么命令、读取了什么文件
5. **禁止**输出类似"以下是查询结果"、"根据您的要求"等过渡性语句
