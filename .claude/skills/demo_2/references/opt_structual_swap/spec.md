# 结构性掉期产品知识说明

## 0. 文档定位
本文件定义结构性掉期报价 agent 的 **产品元知识**

## 1.1 结构性掉期的定义

结构性掉期 = **一个掉期 + 卖出一个期权**

产品设计要求：
> **卖出期权的执行价 K = 掉期远端价格**

该设计要求使得期权的执行价 K 和到期剩余时间 term 绑定：
- 给定 K -> term 唯一确定
- 给定 term -> K 唯一确定
- **同时给 K 和 term → 过约束**(除非 K 和 term 巧合地刚好落在曲线上,否则此定义非法)


## 1.2 方向与期权结构的映射关系

| 用户表达 | 内部方向 | 期权结构 |
|---|---|---|
| 结汇 | `settle` | Sell Put |
| 购汇 | `purchase` | Sell Call |

> 此映射为产品层面的业务约定,不可由模型自行更改。
