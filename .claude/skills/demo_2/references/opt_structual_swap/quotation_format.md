# 结构性掉期产品的报价范式

## 0. 文档定位
本文件定义结构性掉期报价 agent 的 **合法的报价方式**

## 合法的报价范式

1. **基准单点报价**:给一个 K 或一个 term,求对应的另一侧
2. **沿曲线扫描 K**(组合):固定方向,扫一段 term 区间,观察 K 随 term 的变化
3. **沿曲线扫描 term**(组合):固定方向,扫一段 K 区间,观察 term 随 K 的变化
4. **按补贴点数反查**(组合): 给出用户期望的近端补贴点数, agent 在 1M~12M 区间内扫描一组 term,筛选出补贴最接近目标的两个 term 点位返回
5. **方向对比**(组合):结汇 vs 购汇分别报
6. **币种对比**(组合):不同币种对分别报

### 历史格式兼容的标准报价范式

老系统存在六字段位置格式:

```
产品 币种 期限 中收 方向 产品报价
```

**历史六字段格式** 也被视作合法，仅作兼容识别,不作为推荐形态

例如:
```
结构性掉期 USDCNY 3M 100pips 结汇 产品报价
结构性掉期 EURCNY 6M 50 购汇 产品报价
```

## 互斥原则

K 和 term 不能同时指定，如果指定了 K 和 term，则必须通过 `chat` 让用户二选一。
