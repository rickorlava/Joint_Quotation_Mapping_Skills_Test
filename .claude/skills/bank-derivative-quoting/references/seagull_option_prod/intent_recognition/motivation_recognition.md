# 海鸥期权自然语言归一化

## 0. 文档定位
本文件定义海鸥期权报价 agent 的 **输入归一化、结果反推与价格消歧**。

## 1. 输入来源

**自由语言(主路径)**:按「2. 归一化规则」映射为内部约束。

**历史六字段**(兼容,非推荐):

```
产品 币种 期限 中收 方向 产品报价
```

例:`海鸥期权 USDCNY 3M 100pips 结汇 产品报价`。识别要点:首词「海鸥期权」、末词「产品报价」;位2→币种、位3→期限、位4→中收(`100pips`→100)、位5→方向。解析后与自由语言同一套约束对象,勿当独立分支、勿引导用户沿用此格式。

## 2. 归一化规则

### 2.1 执行价直述 → `desired_strikes`

「执行价/行权价/K 7.10」「保护位/别碰到 7.10」。双边「7.00 到 7.20」且语义为**扫两端点** → `[7.00,7.20]`,脚本 5 档梯度。

### 2.2 市场观点 → `desired_strikes`

**否定式**(认为到不了某价):「不会贬值到 7.20」→ settle + 7.20;「不会升值到 6.80」→ purchase + 6.80;「跌破/破 X」→ 结合上下文定方向,不清则 `chat`。

**区间肯定式**(认为大概率在区间内)：大概率在 7.0 - 7.10，**扫两端点** → `[7.00, 7.10]`,脚本 5 档梯度。

**与 2.1 双边区别**:「执行价 7.00 到 7.20 看看」， 大概率在[7.0 7.20], 在7.0 到 7.20 震荡 = **扫两端点** → `[7.00, 7.20], 脚本5档梯度;

**安全边际**(远一点/保守):无数值 → `chat` 补全。

**多表达并存**:优先级 **直述参数 > 否定式 > 区间观点 > 安全边际**。

### 2.3 补贴/收益 → `prem_pips`

「补贴 80 点」「期权费 100 点」等;双边如「50 到 150 点」→ `[50,150]`。

### 2.4 中收 → `profit`

「中收 100」等;双边同理。

### 2.5 结果导向 → `target_all_in_rate`

「结汇在 6.90」「最后做到 6.88」「别低于 6.9」「购汇别高于 7.15」等效果语。

### 2.6 风格 → `delta_preference`

激进:激进/多赚/不怕风险/收益优先。保守:保守/稳/风险小/别太冒险。

## 3. 结果目标反推

仅 `target_all_in_rate`、未直给 `prem_pips` 时:(1) 价档作结果目标,不当默认执行价;(2) 取同期限远期基准;(3) 反推所需补贴点数;(4) 以 `prem_pips` 进标准单目标求解。无直述 `prem_pips` 不代表缺失,可能藏在结果话术中。

### 3.1 结果目标 + 市场观点K → 双边K区间扫描

当 `target_all_in_rate` 与市场观点K**同时出现**时,两个约束**不是**独立目标,不走双目标探索。两者的关系通过产品结构公式关联:

- 海鸥产品结构:`最终结果 = F + C - 中收`(F=远期基准, C=期权费, 均为注册接口已知量)
- `target_all_in_rate` → 代入公式求出 C → 调用反解接口(已知C+term→K) → **K₁**
- 市场观点K(来自"不会跌破/不会升值到") → **K₂**
- K₁ 与 K₂ 构成 K 区间 → 映射至**区间扫描**范式(已存在),脚本按 `--desired-strikes K₁ K₂` 返回5档梯度

**判据**:如果 agent 能通过产品结构公式将 `target_all_in_rate` 反解为某个 K,且该 K 与市场观点K形成区间关系,则一定走区间扫描,不走双目标探索。

> 注意: K₁ 和 K₂ 的大小顺序(即孰为下限孰为上限)由实际反解结果决定,agent 在传参时按数值大小排序即可,不需要预判哪个是下界。

## 4. 价格数字消歧

| 偏执行价 | 偏结果目标 |
|---|---|
| 执行价/行权价/K | 结汇做到/最后做到/拿到手 |
| 保护位/别碰到 | 成交做到/看起来做到 |
| 不会贬/不会升到某价 | 「希望在 X 附近」类效果语 |

仍不清 → `chat` 一次问清。
