# 海鸥期权求解器与组合编排

## 0. 文档定位
本文件定义海鸥期权报价 agent 的 **求解器能力、单次模式选择、组合与预算**。脚本与 Delta 见 `../info/io.md`;输出见 `../output_format.md`。

## 1. 求解器能力

**基准报价器**:给期限、方向、货币对 → 基础方案。

**标准单目标**:在 `term` 下对 `desired_strikes` 或 `prem_pips` 做单点求解或反解。

**双目标探索**:固定 **一个** `term`,同时逼近用户给的 strike 与 `prem_pips` 两目标,脚本通常返回约 5 组折中解。须同时传 `--term` + 单点 `--desired-strikes` + 单点 `--prem-pips`;一次调用透传。探索在 **该 term 切片内的 (strike, prem)** 空间,**不在**期限维寻优。期限不明 → 追问或期限横评组合,**不要**走双目标。

**区间扫描**:单变量区间 → 脚本一次返回 5 档梯度;**禁止** agent 用多次单点调用来模拟。

**风格化**:激进/保守映射 Delta 后报价,见 `../info/io.md`。

**组合**:agent 编排多次调用,见上文「3. 组合求解」。


## 2. 单次模式选择表

| 用户约束                  | 模式 |
|-----------------------|---|
| 仅期限/日期                | 基准 |
| 期限/日期 + 执行价           | 标准单目标 |
| 期限 + 补贴               | 标准单目标 |
| 期限 + 最终成交目标           | 反推 `prem_pips` → 标准单目标 |
| 期限 + 执行价 + 补贴         | 双目标探索 |
| 期限 + 执行价区间            | 区间扫描 |
| 期限 + 补贴区间             | 区间扫描 |
| **期限 + 结果目标 + 市场观点K** | **反推得K₁ → 与K₂构成区间 → 区间扫描**(详见 motivation_recognition.md §3.1) |
| 期限 + 风格               | 风格化 |

## 3. 组合求解

**适用**:单次脚本无法覆盖,且可拆成语义独立、目标清晰的子调用。

**典型**:期限横评;方向对比;风格对比;币种对比;反推后再报;多目标叠加(说明性列举,非封闭白名单)。

**进入条件**(须同时满足):确需多维或分步;每次调用能一句话说清子问题;子调用独立或有明确依赖链。

**预算**:单次任务总调用 ≤ **6**;超限 `chat` 协商拆分;执行中不得临时扩预算。

**先规划后执行**:列出「调用 i: 子问题 → 参数」与汇总方式,再执行;禁止无计划加调用。

**组合 vs 试错**

| 组合 | 试错 |
|---|---|
| 子目标不同 | 目标相同或相似 |
| 新信息、可预期次数 | 冗余、次数失控 |
| 事前有计划 | 事后试 |

两次调用目的分不清 → 合并或删其一。

**汇总**:多结果并成单表,行上标明子调用维度(期限/方向/风格/币种等)。

## 4. 组合求解 补充说明

### 4.1 调用获取远期成本
识别到用户输入的 term, 交割日期delivery-dates, 货币对 currency-pair, 根据 [common_forward_mapping_spec.md](../../common/interface/common_forward_mapping_spec.md)
请求对应的即远期成本报价，得到对应的成本报价。

### 4.2 示例
用户输入 term , 货币对 currency-pair, 方向：结汇  settle-purchase : settle
调用：common_forward_term_with_currency_and_direction 接口，根据字段输出说明，获取 结汇 成本报价

用户输入 交割日期，货币对 currency-pair
调用： common_forward_settle_date_with_currency 接口，根据上下文方向取对应成本价

### 4.2 期限 + 最终成交目标 完整流程说明
> 用户输入：海鸥期权 3M 以6.8结汇
> 识别要素：期限3M 最终报价6.8 
> 流程：
   1. 判定为《期限 + 最终成交目标》场景，先获取 3M 结汇方向 远期成本；
   2. 结汇：最终报价 - 远期结汇成本 = 反解所需的期权pips; 购汇：远期购汇成本 - 最终报价；
   3. 使用 《期限 + 补贴》场景，使用pips反解获取 最终海鸥期权报价；

> 输出：海鸥产品报价
