# 倍享远期（BXYQ） 产品知识 说明

## 0. 文档定位
本文档定义**倍享远期（BXYQ）** 报价的产品 **基础知识、经济本质、产品结构**

## 1、倍享远期-基础知识

### 1.1 产品简述
“倍享远期”是采用期权组合交易方式，实现比正常远期报价更优的远期汇率报价，客户以约定价格交收1倍或数倍的结售汇金额。
在这一业务中，客户承担了交割金额的不确定性，换取了结售汇价格的优惠，适用于有充足结售汇资金流的客户，“倍享远期”可在特定条件下提高我行结售汇报价的市场竞争力。

### 1.2 案例分析
- 1、客户有1年期500万美元至1000万美元的远期结汇需求，叙做双倍“倍享远期”
期初1年期美元对人民币远期结汇价格为6.3600， “倍享远期”可以将远期结汇价格提升到6.4000，条件是到期时交收的结汇金额为500万美元或1000万美元（由银行确定金额），具体交易结构如下：
（1）客户卖出1年期美元看涨人民币看跌期权收取期权费，执行价为6.4000，业务金额为1000万美元。
（2）客户买入1年期美元看跌人民币看涨期权支付期权费，执行价为6.4000，业务金额为500万美元。
收取和支付的期权费相等，在到期日，客户可以以6.4000（比期初远期结汇价6.3600优惠了400点）的价格结汇500万或1000万美金，如下表中所示：
到期日即期汇率	≤6.4000	＞6.4000
客户结汇金额	500万美元	1000万美元
客户结汇价格	6.4000（比期初远期价格优惠了400点）
- 2、以客户一年期500万美元至1500万美元的远期结汇需求为例，叙做多倍“倍享远期”
在例1的基础上，如果客户希望获得比6.4000更高的结汇价，可以叙做多倍“倍享远期”，以三倍“倍享远期”为例：
（1）客户卖出1年期美元看涨人民币看跌期权，执行价为6.4500，业务金额为1500万美元。
（2）客户买入1年期美元看跌人民币看涨期权，执行价为6.4500，业务金额为500万美元。
在到期日，客户可以以6.4500（比期初远期结汇价6.3600优惠了900点）的价格结汇500万或1500万美金，如下表中所示：
到期日即期汇率	≤6.4500	＞6.4500
客户结汇金额	500万美金	1500万美金
客户结汇价格	6.4500（比期初远期价格优惠了900点）

## 2 产品结构

### 2.1 合约组成

#### 结汇方向（Settle）
- 客户卖出 1 份远期（外币 → 本币）
- 客户卖出 n-1 份看涨期权 Call(K)，行权价 K
- 期权与远期本金比 (n-1):1，n 为杠杆倍率

#### 购汇方向（Purchase）
- 客户买入 1 份远期（本币 → 外币）
- 客户卖出 n-1 份看跌期权 Put(K)，行权价 K
- 期权与远期本金比 (n-1):1，n 为杠杆倍率

### 2.2 关键要素

| 要素 | 说明                  |
|------|---------------------|
| 货币对 | 如 USDCNY            |
| 交割日 | 如1Y 、2026-12-12     |
| 方向 | 结汇 / 购汇             |
| 杠杆倍数 n | 期权本金:远期本金 = (n-1):1 |
| 约定汇率 K | 既是远期交割价，也是期权行权价     |
| 中收 profit | 内含于 K 与市场远期价的差额     |
