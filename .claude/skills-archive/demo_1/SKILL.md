# 银行衍生物报价技能

## 概述

本技能用于处理银行衍生物产品的报价请求。它能够从用户输入中提取必要的参数信息，调用相应的报价接口，并返回报价结果。目前支持的产品类型包括结构性掉期、双货币存款和海鸥期权。

## 使用场景

- 用户询问结构性掉期、双货币存款或海鸥期权的报价
- 需要根据用户提供的参数获取银行衍生物产品的报价信息

## 工作流程（必须严格按照以下顺序执行）

1. **产品识别**：根据用户提问识别出对应产品类型（结构性掉期/双货币存款/海鸥期权）
2. **读取参考文档**：读取 `references/` 下对应产品的规格文档
3. **参数提取**：根据参考文档的要求，从用户提问中提取所需参数
4. **执行脚本**：调用 `scripts/` 下对应的报价脚本，**只需要执行一次**，获取报价结果
5. **输出结果**：按照参考文档中规定的输出格式返回报价信息

> **重要**：必须严格按照上述顺序执行，先识别产品，再读取参考文档，然后根据文档要求提取参数、**一次性执行脚本**、输出结果。

## 核心原则：一次性执行

**本技能的核心原则是：报价脚本只需要执行一次。**

### 为什么不能反复调用脚本？
- 脚本已经内置了多种场景的自动判断逻辑
- 反复调用不会获得更好的结果，只会浪费时间
- 脚本会根据输入参数自动选择最合适的报价模式

### 如何做到一次性成功？
1. **仔细阅读参考文档**：每个产品的参考文档都详细说明了参数提取规则和场景判断
2. **正确提取参数**：根据用户输入，提取所有必要参数（货币对、方向、日期/期限等）
3. **选择正确参数组合**：参考文档中有明确的参数组合示例，按图索骥即可
4. **直接执行**：使用正确的参数组合，直接执行一次脚本，不要尝试其他参数

### 如果执行结果不符合预期怎么办？
- 首先检查参数是否正确提取
- 参考文档中的"脚本调用示例"包含了所有支持的参数组合
- **不要通过反复执行脚本来"试错"**，而是回头检查用户输入中是否有遗漏的参数
- 如果用户需求确实无法满足，直接告知用户缺少什么信息

## 注意事项
1. 必须先对用户输入进行翻译后，再进行后续操作
2. 返回格式需按照 `assets/output_format.md` 中的输出格式规范进行返回，使用 <<<TYPE_START>>> <<<TYPE_END>>> <<<CONTENT_START>>> <<<CONTENT_END>>> 格式，不要输出任何无关内容
3. 简洁处理：只需要根据用户的问题识别出对应参数，然后调用脚本进行执行，最后按照要求的格式返回报价信息即可，不要进行多余的分析
4. 批量报价：报价脚本可能会返回一组报价信息（多个执行价或多个期限的报价），需要将这些报价信息全部在表格中返回，供用户自己进行选择
5. 返回类型说明：
   - 出错时：使用 `<<<TYPE_START>>> error <<<TYPE_END>>>`
   - 正常报价：使用 `<<<TYPE_START>>> price <<<TYPE_END>>>`
   - 需要用户补充信息：使用 `<<<TYPE_START>>> chat <<<TYPE_END>>>`
